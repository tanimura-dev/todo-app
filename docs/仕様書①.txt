andoroid　アプリ開発


アプリのコンセプト

「誰でも簡単に使えるシンプルなタスク管理アプリ」


必要な機能

【基本機能】
・タスクを入力して追加できる機能
・タスクを一覧で表示する機能
・タスクを削除する機能

【タスク詳細機能】
・タスクにタイトルを設定できる機能
・タスクに詳細を設定できる機能
・タスクに締め切り日を設定できる機能

【データ管理】
・Roomを使用してタスクをローカルに保存する機能
・アプリ起動時に保存されたタスクを取得して表示する機能

【外部連携】
・APIから名言を取得する機能（Retrofit）
・取得した名言を画面に表示する機能



データ設計

① Task（メイン）
import androidx.room.Entity
import androidx.room.PrimaryKey

@Entity(tableName = "tasks")
data class Task(
    @PrimaryKey(autoGenerate = true)
    val id: Int = 0,

    val title: String,                 // 必須
    val description: String = "",      // 空OK
    val deadline: String? = null,      // nullOK
    val isDone: Boolean = false        // 状態
)

② 名言（API用）
data class Quote(
    val content: String,   // 名言の内容
    val author: String? = null     // 誰の言葉か
)
