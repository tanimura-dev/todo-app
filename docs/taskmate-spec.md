# Androidアプリ開発最終課題仕様書

## アプリ名

**「TaskMate」**

## コンセプト

「誰でも簡単に使えるシンプルなタスク管理」

「Mate」は「仲間・相棒」という意味を持ち、日々のタスク管理をサポートする身近なアプリを目指している。
複雑な機能を減らし、誰でも直感的に利用できるシンプルなタスク管理アプリとして、ユーザーの日常の作業をサポートする。

---

## ターゲットユーザー

* タスクを簡単に管理したい人
* 複雑な機能を必要とせず、シンプルな管理を求める人
* 日々の作業や予定を整理したい人

---

## アプリの目的

* タスクの登録、確認、削除を簡単に行えるようにする
* 必要最低限の機能で使いやすいタスク管理環境を提供する
* ユーザーのタスク管理を支える身近なアプリを目指す

---

## 主な機能

### 1. タスク管理機能

* タスクを追加できる
* 登録したタスクを一覧表示できる
* タスクを削除できる
* タスクの完了状態を管理できる

### 2. タスク詳細機能

* タイトルを設定できる（必須）
* 詳細内容を設定できる（任意）
* 締め切り日を設定できる（任意）

### 3. データ管理機能

* Roomを使用してタスクをローカル保存する
* アプリ起動時に保存済みのタスクを取得して表示する
* アプリ終了後もデータを保持する

### 4. 外部連携機能

* Retrofitを使用してAPIから名言を取得する
* 取得した名言を画面に表示する
* タスク一覧画面を表示するたびに名言を再取得する（他画面から戻った際も新しい名言に切り替わる）

---

## 画面構成

### 1. タスク一覧画面

* 登録されたタスクを一覧表示する
* 画面上部に名言を表示する
* FABボタンからタスク追加画面へ移動する

### 2. タスク追加画面

* タイトル、詳細、締め切り日を入力できる
* 保存ボタンでタスクを登録する
* 登録後、タスク一覧画面へ戻る

### 3. タスク詳細画面

* タスクの詳細情報を表示する
* タスクを削除できる

## データ設計

### ① Task（タスク管理）

```kotlin
@Entity
data class Task(
    @PrimaryKey(autoGenerate = true)
    val id: Int = 0,
    val title: String,
    val description: String,
    val deadline: String,
    val isCompleted: Boolean = false,
    val createdAt: Long = System.currentTimeMillis(),
)
```

#### 項目

| 項目          | 説明              |
|-------------|-----------------|
| id          | タスク識別用ID        |
| title       | タスクタイトル         |
| description | タスク詳細           |
| deadline    | 締め切り日（未設定は空文字）  |
| isCompleted | 完了状態            |
| createdAt   | 作成日時（一覧の並び順に使用） |

---

### ② Quote（名言API用）

```kotlin
data class Quote(
    val meigen: String,
    val auther: String,
)
```

#### 項目

| 項目      | 説明                      |
|---------|-------------------------|
| meigen  | 名言内容（API のレスポンスキーに準拠）   |
| auther  | 発言者（API 側のスペルミスをそのまま採用） |

## 技術スタック

* Kotlin（Androidアプリ開発言語）
* Jetpack Compose（UI作成）
* Room（タスクデータ保存）
* Retrofit（API通信）
* ViewModel（状態管理）
* Navigation Component（画面遷移）
* Coroutine（非同期処理）
